# Kddesmond99 Personal Website

A clean, responsive personal website for Kddesmond99.

## Files
- `index.html` — page structure and SEO metadata
- `style.css` — responsive design
- `script.js` — mobile navigation and dynamic year

## Before publishing
Replace the placeholder social/profile URLs in `index.html` with your real:
- Instagram
- GitHub
- WebNovel
- Royal Road
- Any other profile you want Google to associate with your name

For the strongest personal-brand effect, keep the same name/username (`Kddesmond99`) across your profiles.

## Publishing
This is a static site, so it can be hosted on GitHub Pages, Netlify, Vercel, or another static hosting service.
